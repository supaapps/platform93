# Security Policy

Platform93 is pre-release and does not yet have supported production versions.

Do not disclose suspected vulnerabilities in public issues. Contact the repository
maintainers privately through GitHub security advisories.

Never include production credentials, access tokens, personal data, or complete
exploit payloads containing third-party data in a report. Use minimal synthetic
reproduction material.

Security support and release-signing details will be published before the first
production release.
